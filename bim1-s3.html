Semana 03 • Aula 01

Condição simples: introdução ao SE

Até agora, nossos programas executavam todas as instruções de forma estritamente sequencial. Com a estrutura de decisão SE (ou if), o algoritmo ganha a capacidade de avaliar uma condição lógica antes de executar um bloco de código.

O Mecanismo da Decisão Simples

[Avalia Condição?] → (Verdadeiro) → Executa o Bloco Interno
[Avalia Condição?] → (Falso) → Segue o Fluxo Normal (Ignora o Bloco)
  • Estrutura Básica: Se a condição for verdadeira, os comandos internos são executados; caso contrário, o programa pula esse bloco.
Semana 03 • Aula 02

Condição composta: SE…SENÃO

Muitas situações exigem que o programa tome caminhos alternativos: se uma condição for verdadeira, faz uma coisa; caso contrário (SENÃO / else), executa uma instrução diferente.

Estrutura Lógica Comportamento no Programa
SE (Condição) Executado apenas se o resultado da expressão lógica for verdadeiro.
SENÃO Executado obrigatoriamente se a expressão lógica principal resultar em falso.
Semana 03 • Aula 03

Condições aninhadas: SE dentro de SE

Quando precisamos lidar com múltiplos critérios e faixas de decisão complexas, utilizamos o aninhamento — que consiste em colocar uma estrutura SE...SENÃO inteira dentro do bloco de outra condição.

  • Múltiplos Caminhos: Permite classificar dados em várias categorias distintas (por exemplo: diferenciar conceitos escolares como Aprovado, Recuperação ou Reprovado com base em faixas de notas).
  • Cuidados de Indentação: Manter o código bem recuado é essencial para não perder o controle de qual SENÃO pertence a qual SE.
