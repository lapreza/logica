Introdução às Estruturas de Decisão Composta

Nesta semana você irá implementar estruturas de decisão composta (SE…SENÃO) para desenvolver algoritmos que lidam com múltiplos caminhos e condições, resolvendo problemas mais complexos[cite: 2].

Semana 07 • Aula 01

Estrutura SE / SENÃO

A estrutura de decisão composta amplia a lógica condicional oferecendo uma alternativa obrigatória. Se a condição principal for verdadeira, um bloco de comandos é executado; caso contrário, o bloco associado ao SENÃO (else) é acionado automaticamente[cite: 2].

O Fluxo de Duas Vias

[Avalia Condição] → (Verdadeiro) → Bloco SE
[Avalia Condição] → (Falso) → Bloco SENÃO
  • Exclusividade Mútua: Apenas um dos dois blocos (o do SE ou o do SENÃO) será executado em cada execução do programa.
Semana 07 • Aula 02

Variações com comparações encadeadas

Quando um problema exige a escolha entre três ou mais caminhos possíveis (como classificar notas em múltiplos conceitos ou faixas etárias), utilizamos o encadeamento de estruturas condicionais compostas (SE... SENAO SE... SENAO)[cite: 2].

Tipo de Decisão Estrutura Utilizada Finalidade Principal
Simples Apenas SE Executa uma ação se verdadeiro; ignora se falso.
Composta SE ... SENÃO Escolhe obrigatoriamente entre duas ações exclusivas.
Encadeada SE ... SENÃO SE ... SENÃO Trata múltiplos cenários e faixas de decisão hierárquicas.
Semana 07 • Aula 03

Fluxogramas com decisão composta

Nos diagramas de blocos, a decisão composta utiliza o símbolo de Losango ramificando o fluxo em duas direções simétricas e bem definidas: o ramo esquerdo para o caso verdadeiro e o ramo direito para o caso falso[cite: 2].

  • Convergência: Após a execução do bloco correspondente (seja o do SE ou o do SENÃO), os caminhos voltam a se unir no fluxo principal do algoritmo.
Semana 07 • Aula 04

Prática com decisão composta

Nesta aula final do 1º bimestre, consolidamos o aprendizado de desvios condicionais compostos e encadeados resolvendo problemas práticos de classificação[cite: 2].

Fechamento do 1º Bimestre • Sistema de Avaliação Escolar Desenvolver um algoritmo completo que lê a nota final de um aluno e, utilizando uma estrutura composta encadeada, classifica e exibe se o estudante está Aprovado, em Recuperação ou Reprovado.
