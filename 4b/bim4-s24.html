Semana 24 • Aula 01

Como funciona um programa interativo

Programas interativos exigem uma troca contínua de mensagens entre o usuário e a máquina. Diferente de um cadastro passivo, o quiz responde imediatamente a cada escolha, alterando o fluxo com base no acerto ou erro.

A Dinâmica de Ação e Reação

[Exibe Pergunta] → Lê Resposta do Usuário → Compara com o Gabarito → [Atualiza Pontuação / Feedback]
  • Estado Dinâmico: Variáveis de controle (como pontos e tentativas) são modificadas a cada rodada.
  • Validação de Resposta: Garantir que o usuário digite apenas opções válidas (por exemplo, alternativas A, B, C, D ou números equivalentes).
Semana 24 • Aula 02

Perguntas, tentativas e pontuação

Para estructurar um jogo de perguntas e respostas robusto, organizamos vetores paralelos contendo os enunciados, as alternativas e a resposta correta de cada questão.

Componente do Quiz Tipo de Dado Finalidade no Programa
Enunciados Vetor de cadeia Armazena o texto da pergunta exibida ao jogador.
Gabarito Vetor de inteiro ou caractere Guarda a alternativa correta para validação automática.
Pontuação Variável inteira (pontos) Acumula os pontos a cada resposta certa.
Semana 24 • Aula 03

Programando rodadas e pontuação no projeto

Nesta aula, implementamos a estrutura de repetição (como um laço para) que percorre o vetor de perguntas, gerencia as rodadas sequencialmente e soma pontos ao placar geral.

Exemplo de Lógica do Quiz em Código

// Estrutura de rodadas de um Quiz
inteiro pontos = 0
cadeia respostaUsuario

escreva("\n==================================")
escreva("\n         DESAFIO DE LÓGICA        ")
escreva("\n==================================")

// Pergunta 1
escreva("\n1. Qual símbolo representa a estrutura de decisão condicional básica?\n")
escreva("a) enquanto\n")
escreva("b) se\n")
escreva("c) para\n")
escreva("Sua resposta: ")
leia(respostaUsuario)

se (respostaUsuario == "b" ou respostaUsuario == "B") {
    escreva("-> Resposta Correta! +10 pontos.\n")
    pontos = pontos + 10
} senao {
    escreva("-> Resposta Incorreta. A resposta certa era 'b'.\n")
}

escreva("\nPontuação atual: ", pontos, " pontos.\n")
Semana 24 • Aula 04

Ampliando com o quiz temático

Para finalizar a semana, expandimos o sistema criando um Quiz Temático (focado em tecnologia, história ou conhecimentos gerais), integrando vetores de perguntas maiores e exibindo um relatório final de desempenho com classificação baseada na pontuação obtida.
