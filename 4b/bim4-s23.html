Semana 23 • Aula 01

De critérios a regras de classificação

Muitos sistemas do mundo real precisam transformar números crus (como notas, pontuações de jogos ou temperaturas) em categorias qualitativas ou conceitos (como Aprovado, Em Recuperação, Nível Iniciante ou Avançado).

Mapeando Critérios em Estruturas Condicionais

Para programar essas regras, traduzimos as faixas numéricas em estruturas de decisão encadeadas (se... senao se... senao), garantindo que os limites não se sobreponham e cobrem todas as possibilidades de entrada.

  • Definição Clara de Limites: Evitar lacunas lógicas (por exemplo, o que acontece exatamente se a nota for 5.9?).
  • Ordem das Condições: Em testes de faixas decrescentes ou crescentes, a ordem dos testes condicionais é determinante para evitar falsos positivos.
Semana 23 • Aula 02

Organizar o cálculo para ficar claro e reutilizável

Quando um cálculo aritmético ou regra de negócio é repetido em vários pontos do código, o ideal é isolá-lo em uma função com retorno. Isso evita repetição de código e centraliza manutenções futuras.

Exemplo de Função de Cálculo Reutilizável

// Função que calcula a média aritmética entre duas notas e retorna o valor
funcao real calcularMedia(real nota1, real nota2) {
    real media
    media = (nota1 + nota2) / 2.0
    retorne media
}

// Função que classifica o conceito com base na média recebida
cadeia classificarConceito(real media) {
    se (media >= 7.0) {
        retorne "Aprovado"
    } senao se (media >= 5.0) {
        retorne "Em Recuperação"
    } senao {
        retorne "Reprovado"
    }
}
Semana 23 • Aula 03

Calculando médias e classificando no projeto

Nesta aula, aplicamos as funções de cálculo de média e classificação diretamente aos cadastros armazenados em memória (como expandir o cadastro de alunos ou itens de desempenho do projeto).

Integrando o Cálculo ao Sistema

Ao listar cada registro cadastrado, o programa agora processa os dados numéricos em tempo de execução, exibindo não apenas os valores brutos, mas também o status correspondente gerado pelas regras de classificação.

Semana 23 • Aula 04

Ampliando com ranking

Para encerrar a semana, damos um passo além na manipulação de vetores: criamos uma rotina para ordenar os dados com base nas notas ou pontuações, gerando um ranking decrescente no terminal.

Lógica de Ordenação Simples (Bubble Sort Conceitual)

Comparamos elementos adjacentes do vetor e os permutamos caso estejam fora de ordem, permitindo ao sistema listar os melhores colocados do topo para a base.

Atividade Prática • Sistema de Médias e Ranking Implementar no projeto a rotina que calcula médias com base em dados informados pelo usuário, classifica cada registro em faixas predefinidas e exibe um ranking ordenado no terminal.
