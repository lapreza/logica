Semana 22 • Aula 01

Como guardar dados sem usar arquivo

Até o momento, nossas variáveis comuns guardavam apenas um valor por vez (por exemplo, um único nome ou um único número), que era substituído assim que uma nova entrada era realizada. Para gerenciar múltiplos registros (como vários contatos em uma agenda), utilizamos estruturas de dados em memória RAM: Vetores (Arrays) ou Listas Paralelas.

Organização com Vetores Paralelos

[Índice 0] → Nome: Ana | Telefone: 9991-2345
[Índice 1] → Nome: Carlos | Telefone: 9882-5678
[Índice 2] → Nome: Beatriz | Telefone: 9773-9012
  • Controle de Posição (Contador / Ponteiro): Precisamos de uma variável inteira (ex: totalCadastrados) que indique quantas posições do vetor estão realmente ocupadas em um dado momento.
  • Vantagem e Limitação: O acesso em memória é extremamente rápido, mas os dados armazenados são voláteis — ou seja, são apagados assim que o programa é fechado.
Semana 22 • Aula 02

Incluir, consultar e listar: a lógica por trás

Todo sistema de cadastro básico é composto por três operações essenciais que operam diretamente sobre os vetores em memória:

Operação Lógica de Funcionamento Cuidados Necessários
Incluir (Inserir) Armazena os dados digitados na próxima posição disponível do vetor e incrementa o contador. Verificar se o vetor atingiu sua capacidade máxima (estouro de limite).
Consultar (Buscar) Percorre o vetor com um laço de repetição comparando o termo buscado com os dados armazenados. Tratar o caso em que o registro não é encontrado (retornar aviso claro).
Listar (Exibir Todos) Utiliza um laço (como para) de 0 até o limite do contador para mostrar todos os registros salvos. Verificar se o cadastro está vazio antes de tentar exibir a listagem.
Semana 22 • Aula 03

Cadastrando e consultando no projeto

Nesta aula, implementamos as funções de inclusão e busca por nome na nossa agenda de contatos integrada ao menu terminal da semana anterior.

Exemplo de Lógica em Código

// Estrutura de dados em memória para a Agenda
const inteiro MAX_CONTATOS = 50
cadeia nomes[MAX_CONTATOS]
cadeia telefones[MAX_CONTATOS]
inteiro totalContatos = 0

funcao incluirContato() {
    se (totalContatos < MAX_CONTATOS) {
        escreva("\n--- NOVO CONTATO ---")
        escreva("\nDigite o nome: ")
        leia(nomes[totalContatos])
        escreva("Digite o telefone: ")
        leia(telefones[totalContatos])
        
        totalContatos++
        escreva("\n[Sucesso] Contato cadastrado com sucesso!\n")
    } senao {
        escreva("\n[Erro] Agenda cheia! Limite máximo atingido.\n")
    }
}

funcao consultarContato() {
    cadeia busca
    logico encontrado = falso
    
    escreva("\nDigite o nome que deseja buscar: ")
    leia(busca)
    
    para (inteiro i = 0; i < totalContatos; i++) {
        se (nomes[i] == busca) {
            escreva("\nEncontrado na posição ", i + 1)
            escreva("\nNome: ", nomes[i])
            escreva("\nTelefone: ", telefones[i], "\n")
            encontrado = verdadeiro
            pare
        }
    }
    
    se (!encontrado) {
        escreva("\n[Aviso] Nenhum contato encontrado com o nome '", busca, "'.\n")
    }
}
Semana 22 • Aula 04

Ampliando o cadastro com listagem

Para encerrar a semana, adicionamos a opção de listagem geral de todos os contatos salvos e integramos todas as operações (Incluir, Consultar, Listar e Sair) dentro do menu principal do sistema.

Rotina de Listagem Geral

funcao listarContatos() {
    se (totalContatos == 0) {
        escreva("\n[Aviso] A agenda está vazia no momento.\n")
    } senao {
        escreva("\n==================================")
        escreva("\n          LISTA DE CONTATOS       ")
        escreva("\n==================================")
        para (inteiro i = 0; i < totalContatos; i++) {
            escreva("\n[", i + 1, "] Nome: ", nomes[i], " | Tel: ", telefones[i])
        }
        escreva("\n----------------------------------")
        escreva("\nTotal de contatos: ", totalContatos, "\n")
    }
}
