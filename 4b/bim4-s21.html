Semana 21 • Aula 01

Como um programa com menu se organiza

Até agora, criamos programas sequenciais que executavam de cima para baixo e encerravam em seguida. Sistemas reais, no entanto, precisam permanecer ativos permitindo que o usuário escolha o que deseja fazer repetidas vezes.

A Estrutura de Ciclo e Escolha

[Início] → Exibir Opções do Menu → Ler Escolha do Usuário → Decidir (Escolha == Sair?) → [Fim / Repetir]
  • Laço de Repetição (Loop): Garante que o menu seja reexibido após cada operação concluída, encerrando apenas quando o usuário digitar a opção de saída (por exemplo, 0 ou Sair).
  • Decisão (Switch/Case ou If/Else Aninhado): Direciona o fluxo do programa para a rotina específica correspondente à opção escolhida.
Semana 21 • Aula 02

Por que usar funções e validar entradas

Colocar todo o código de um sistema dentro do programa principal (como o bloco main) gera um código confuso e difícil de manter. A divisão em funções isola responsabilidades.

Vantagens da Modularização e Validação

  • Funções Especializadas: Cada função deve executar uma única tarefa clara (ex.: exibirCabecalho(), lerOpcaoMenu(), validarNumero()).
  • Tratamento de Entradas Inválidas: O usuário pode digitar letras quando o sistema espera um número, ou escolher uma opção inexistente (ex: digitar 9 em um menu de 1 a 3). Validar a entrada impede que o programa feche com erro inesperado.
// Exemplo em Portugol / Lógica estruturada
funcao inteiro lerOpcaoValida() {
    inteiro opcao
    faca {
        escreva("\nDigite sua opção: ")
        leia(opcao)
        se (opcao < 0 ou opcao > 3) {
            escreva("Opção inválida! Tente novamente.")
        }
    } enquanto (opcao < 0 ou opcao > 3)
    retorne opcao
}
Semana 21 • Aula 03

Construindo o menu do projeto

Nesta aula, iniciamos a estrutura base do projeto do 4º bimestre, integrando o laço de repetição com a exibição limpa das opções disponíveis no terminal.

Esqueleto Base do Sistema

// Estrutura principal do projeto no terminal
inteiro opcao = -1

faca {
    escreva("\n============================")
    escreva("\n   SISTEMA DE GERENCIAMENTO  ")
    escreva("\n============================")
    escreva("\n1. Executar Primeira Opção")
    escreva("\n2. Opção Futura (Em breve)")
    escreva("\n3. Opção Futura (Em breve)")
    escreva("\n0. Sair do Sistema")
    escreva("\n----------------------------")
    
    opcao = lerOpcaoValida()

    escolha (opcao) {
        caso 1:
            escreva("\n-> Executando a Opção 1...\n")
            // Chamada da função específica aqui
            pare
        caso 2:
        caso 3:
            escreva("\n[Aviso] Funcionalidade em desenvolvimento.\n")
            pare
        caso 0:
            escreva("\nEncerrando o sistema. Até logo!\n")
            pare
        caso contrario:
            escreva("\n[Erro] Opção desconhecida.\n")
    }
} enquanto (opcao != 0)

Ampliando o menu com a primeira opção executável

Vamos transformar a opção 1 do nosso menu em uma rotina real e funcional, aplicando parâmetros, variáveis locais e retorno de dados.

Implementando a Funcionalidade Inicial

A primeira opção executável do projeto funcionará como um módulo de saudação personalizada ou cálculo rápido integrado ao menu principal, demonstrando a passagem de controle entre o laço principal e a função dedicada.

Atividade Prática • Menu Funcional no Terminal Escrever o programa completo no ambiente de testes escolhido, garantindo que o menu se repita corretamente até que o usuário digite 0, e testando se a opção 1 executa a rotina programada sem interromper o ciclo principal.
