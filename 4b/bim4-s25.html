Semana 25 • Aula 01

Enxergando o sistema por partes

À medida que os programas crescem, escrever todo o código em um único bloco contínuo torna-se inviável. Um software profissional é concebido de forma modular, dividido em subsistemas ou módulos independentes que cooperam entre si.

A Abordagem Modular

[Menu Principal] → Módulo de Cadastros | Módulo de Consultas | Módulo de Relatórios/Cálculos
  • Divisão de Responsabilidades: Cada parte do sistema resolve um problema específico, facilitando a identificação de erros e a implementação de melhorias.
  • Escalabilidade: Adicionar uma nova funcionalidade passa a exigir apenas a criação de um novo módulo, sem que seja necessário reescrever a lógica existente.
Semana 25 • Aula 02

Quem faz o quê: dados e funções

Para estruturar um minissistema integrado, é fundamental separar claramente o armazenamento de informações (os dados nos vetores) das regras de processamento (as funções).

Camada do Sistema Elementos Principais Responsabilidade
Estrutura de Dados Vetores globais ou locais (ex: nomes, valores, status). Guardar o estado e o histórico das informações em memória RAM.
Processamento (Funções) Rotinas de cálculo, validação, inserção e exibição. Manipular os dados aplicando as regras de negócio do sistema.
Semana 25 • Aula 03

Montando o minissistema

Nesta aula, unificamos os conceitos aprendidos ao longo do bimestre — menus interativos no terminal, cadastros em memória com vetores e regras de cálculo e classificação — estruturando a base central do minissistema integrado.

Arquitetura do Minissistema

// Esqueleto geral integrando o Menu Principal às Funções Especializadas
funcao inicio() {
    inteiro opcao = -1
    
    faca {
        escreva("\n==================================")
        escreva("\n      MINISSISTEMA INTEGRADO      ")
        escreva("\n==================================")
        escreva("\n1. Gerenciar Cadastros")
        escreva("\n2. Executar Cálculos e Relatórios")
        escreva("\n3. Central de Desafios / Quiz")
        escreva("\n0. Sair do Programa")
        escreva("\n----------------------------------")
        escreva("\nEscolha sua opção: ")
        leia(opcao)

        escolha (opcao) {
            caso 1: menuCadastros() pare
            caso 2: menuRelatorios() pare
            caso 3: menuQuiz() pare
            caso 0: escreva("\nEncerrando o minissistema...\n") pare
            caso contrario: escreva("\n[Erro] Opção inválida!\n")
        }
    } enquanto (opcao != 0)
}

Completando as opções do sistema

Para concluir a semana, preenchemos todas as ramificações pendentes do menu, garantindo que cada opção leve a uma rotina totalmente executável e integrada aos dados do sistema.
