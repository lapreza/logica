Conceitos de Entrada, Processamento e Saída

Nesta semana você irá aplicar as estruturas de entrada, processamento e saída de dados para construir seus primeiros programas que interagem com o usuário, recebendo informações e apresentando resultados.

Semana 02 • Aula 01

Entrada de dados

A Entrada de dados representa o mecanismo pelo qual o programa obtém informações externas — geralmente fornecidas pelo usuário através do teclado, de sensores ou de arquivos.

O Papel da Leitura de Dados

  • Interatividade: Permite que o software deixe de ser estático e reaja de acordo com o que o usuário digita (por exemplo, ler um nome, uma idade ou valores monetários).
  • Instruções de Leitura: Na maioria das linguagens e pseudocódigos, utilizamos comandos específicos como leia() ou input() associados a uma variável de destino.
Semana 02 • Aula 02

Processamento de dados

O Processamento é o coração lógico do programa. É a etapa onde os dados de entrada são manipulados, combinados, submetidos a cálculos matemáticos ou avaliados por expressões lógicas.

[Entrada: nota1, nota2] → Processamento: (nota1 + nota2) / 2 → [Armazena na variável media]
  • Atribuição (<- ou =): Guarda o resultado de uma operação em uma variável para uso posterior.
  • Operadores Aritméticos: Adição (+), subtração (-), multiplicação (*), divisão (/) e resto da divisão (%).
Semana 02 • Aula 03

Saída de dados

A Saída de dados é a forma como o sistema devolve o resultado processado para o usuário, seja exibindo informações na tela do monitor, gerando relatórios ou gravando arquivos.

  • Comandos de Exibição: Utilizamos instruções como escreva(), imprimir() ou print().
  • Formatação de Mensagens: Concatenar textos fixos com o valor armazenado em variáveis (por exemplo: escreva("A média final é: ", media)).

Exercícios integrados (Entrada, Processamento e Saída)

Nesta aula prática, unimos os três pilares fundamentais da computação em um programa completo que simula um ciclo lógico real.

Etapa do Ciclo Exemplo Prático (Calculadora de Média)
1. Entrada Ler duas notas digitadas pelo usuário (leia(n1), leia(n2)).
2. Processamento Somar as notas e dividir por 2 (media <- (n1 + n2) / 2).
3. Saída Exibir o valor da média calculada na tela (escreva(media)).
Atividade Prática • Algoritmo de Conversão de Moeda Escrever o fluxograma e o algoritmo completo que recebe um valor em Reais, processa a conversão para Dólar com base em uma cotação fixa e exibe o resultado final formatado na tela.
