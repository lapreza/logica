Semana 05 • Aula 01

Tomada de decisão com SE

A tomada de decisão é o ponto onde o algoritmo ganha autonomia condicional. Com o comando SE (if), o programa avalia uma expressão lógica e determina se um determinado trecho de código deve ou não ser executado[cite: 2].

A Mecânica da Avaliação Lógica

  • Condição Verdadeira: O fluxo adentra o bloco interno e executa as instruções delimitadas.
  • Condição Falsa: O bloco interno é completamente ignorado, prosseguindo com o restante do algoritmo.
Semana 05 • Aula 02

Estrutura sequencial combinada com SE

Programas reais misturam comandos sequenciais tradicionais (leitura de dados e cálculos básicos) com pontos de desvio condicional usando o SE[cite: 2].

[Entrada de Dados] → [Processamento Sequencial] → [Avaliação SE] → [Saída Condicional]
  • Ordem de Execução: A estrutura sequencial prepara os dados que serão testados logo em seguida pela condição lógica.
Semana 05 • Aula 03

Fluxograma com decisão simples

Na representação gráfica, a decisão simples utiliza o símbolo de Losango, de onde partem duas setas direcionenciais distintas: uma indicando o caminho para o fluxo verdadeiro e outra contornando o bloco caso o resultado seja falso[cite: 2].

Elemento do Fluxograma Função na Decisão Simples
Losango Contém a pergunta ou condição lógica (ex: nota >= 6.0?).
Seta "Sim" / "Verdadeiro" Direciona o fluxo para a execução das instruções internas.
Seta "Não" / "Falso" Contorna o bloco condicional e segue para a próxima instrução comum.
Semana 05 • Aula 04

Aplicações com SE (atividade prática)

Nesta aula prática, aplicamos o comando SE isolado para resolver problemas básicos de verificação e alertas no terminal[cite: 2].

Atividade Prática • Alerta de Velocidade Máxima Construir um algoritmo que lê a velocidade de um veículo em uma via. Se a velocidade informada ultrapassar 80 km/h, o programa deve exibir na tela uma mensagem de infração por excesso de velocidade; caso contrário, não exibe nenhum alerta adicional.
