Matrizes bidimensionais

Nesta semana você irá declarar e percorrer matrizes bidimensionais para modelar e manipular dados tabulares, permitindo a criação de soluções como planilhas ou o tabuleiro de um jogo.

Semana 16 • Aula 01

Conceito, declaração e visualização de matrizes

As matrizes bidimensionais estendem o conceito de vetores para uma estrutura de linhas e colunas, assemelhando-se a uma tabela ou planilha eletrônica[cite: 2].

Organização Tabular

  • Duplo Índice: Cada dado armazenado é referenciado por coordenadas de linha e coluna (ex: `matriz[linha][coluna]`).
  • Modelagem: Ideal para representar tabuleiros, mapas e bases de dados tabulares simples.
Semana 16 • Aula 02

Laços aninhados para percorrer matrizes

Para varrer todas as células de uma matriz, empregamos estruturas de repetição aninhadas: o loop externo controla o avanço das linhas, enquanto o loop interno percorre todas as colunas de cada linha[cite: 2].

[Linha 0] → Coluna 0 | Coluna 1 | Coluna 2
[Linha 1] → Coluna 0 | Coluna 1 | Coluna 2
Semana 16 • Aula 03

Agregação de dados em matrizes

Através da varredura sistemática dos elementos tabulares, é possível calcular somas parciais por linhas/colunas ou totais gerais consolidados[cite: 2].

Tipo de Agregação Lógica de Processamento
Por Linha Acumula os valores de todas as colunas pertencentes a uma mesma linha.
Global / Total Soma todas as células da matriz para extrair o valor consolidado geral.
Semana 16 • Aula 04

Miniprojeto “Planilha de vendas”

Nesta aula prática integrada, aplicamos matrizes bidimensionais para resolver um problema real de negócios[cite: 2].

Atividade Prática • Planilha de Vendas Desenvolver um sistema que armazena os valores de vendas mensais de diferentes produtos organizados em matriz, calculando o total vendido por produto e o faturamento total da empresa no período.
