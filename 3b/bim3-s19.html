Semana 19 • Aula 01

Revisão do tipo string e imutabilidade

As cadeias de caracteres (strings) representam dados textuais fundamentais em qualquer sistema. O entendimento de sua estrutura interna e comportamento é o primeiro passo para o processamento de textos[cite: 2].

Conceitos Fundamentais

  • Imutabilidade: Uma vez criada, o conteúdo de uma string não pode ser alterado diretamente em seu espaço de memória original; operações de modificação geram novas instâncias.
Semana 19 • Aula 02

Métodos de busca e substituição

Linguagens de programação modernas oferecem nativamente uma série de métodos utilitários para localizar substrings, verificar prefixos/sufixos e trocar partes de um texto[cite: 2].

Operação Textual Finalidade Lógica
Busca (Find / Index) Localiza a posição exata de ocorrência de um caractere ou palavra dentro do texto.
Substituição (Replace) Varre o texto trocando ocorrências de um termo específico por outro valor desejado.

Slicing e formatação com fstrings

O fatiamento (`slicing`) permite extrair fatias ou intervalos específicos de uma string utilizando índices, enquanto as interpolações dinâmicas (`f-strings`) otimizam a formatação de saídas textuais[cite: 2].

Parsing de logs

Nesta aula prática, aplicamos técnicas avançadas de manipulação de strings para analisar arquivos de registro (logs) e extrair informações úteis[cite: 2].
