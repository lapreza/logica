Semana 20 • Aula 01

Arquivos – entrada e saída

Até agora, os dados dos nossos programas eram voláteis (perdidos ao fechar a execução). A manipulação de arquivos (E/S ou I/O) garante a persistência das informações em disco[cite: 2].

Conceitos de Persistência

  • Modos de Abertura: Leitura (`r`), escrita (`w`) e anexação (`a`), permitindo gerenciar o ciclo de vida dos dados externos.
Semana 20 • Aula 02

Leitura linha a linha

Para processar grandes volumes de dados textuais sem esgotar a memória RAM, utilizamos a leitura sequencial fracionada, percorrendo o arquivo linha por linha[cite: 2].

[Arquivo em Disco] → Lê Linha 1 → Lê Linha 2 → [Processamento Iterativo]
Semana 20 • Aula 03

Escrita de relatórios

A capacidade de gerar arquivos de texto estruturados em disco permite que os algoritmos produzam relatórios consolidados automáticos para análise posterior[cite: 2].

Operação de Escrita Comportamento Técnico
Sobrescrita (`w`) Cria um novo arquivo ou substitui integralmente o conteúdo pré-existente.
Anexação (`a`) Adiciona novos registros ao final do arquivo preservando o histórico anterior.
Semana 20 • Aula 04

Integração com CSV

Nesta aula prática, aplicamos a persistência de arquivos para ler e gravar dados tabulares estruturados no formato padrão CSV (Comma-Separated Values)[cite: 2].

Atividade Prática • Processador de Arquivos CSV Desenvolver um sistema que lê uma base de dados tabulares em formato CSV, realiza filtragens lógicas e grava um novo relatório persistido em disco.
