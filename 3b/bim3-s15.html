Vetores (arrays) unidimensionais

Nesta semana você irá criar e percorrer vetores (arrays) para manipular coleções de dados, uma base essencial para implementar algoritmos de busca e análise de informações.

Aula 01 Declaração e inicialização de vetores Aula 02 Percurso sequencial de vetores Aula 03 Busca linear e estatísticas simples Aula 04 Oficina prática – “Notas da turma”
Semana 15 • Aula 01

Declaração e inicialização de vetores

Os vetores (arrays unidimensionais) permitem armazenar múltiplos valores de um mesmo tipo sob uma única estrutura de dados organizada por posições sequenciais[cite: 2].

Conceitos Iniciais

  • Indexação: Cada elemento do vetor é acessado por meio de um índice numérico, que tipicamente inicia em zero.
  • Alocação: Reserva de espaço na memória para acomodar o tamanho estipulado da lista de dados.
Semana 15 • Aula 02

Percurso sequencial de vetores

Para visitar, exibir ou modificar cada elemento armazenado em um vetor, utilizamos estruturas de repetição (como o for) para percorrer a lista de ponta a ponta[cite: 2].

[Início do Vetor] → Índice 0 → Índice 1 → ... → [Fim do Vetor]
Semana 15 • Aula 03

Busca linear e estatísticas simples

Combinando vetores e laços condicionais, podemos realizar varreduras para encontrar elementos específicos (busca linear) ou calcular métricas agregadas, como valores máximos, mínimos e médias[cite: 2].

Operação em Vetores Objetivo Lógico
Busca Linear Percorre o vetor sequencialmente comparando cada item com o valor procurado.
Estatísticas Acumula valores para extrair somas, médias, maiores e menores ocorrências.
Semana 15 • Aula 04

Oficina prática – “Notas da turma”

Nesta oficina prática, aplicamos os conceitos de vetores para gerenciar um cenário real de processamento de dados acadêmicos[cite: 2].

Atividade Prática • Sistema Notas da Turma Desenvolver um programa que armazena em um vetor as notas de vários alunos, calcula a média geral da turma e identifica quais notas ficaram acima da média calculada.
