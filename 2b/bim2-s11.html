Vetores (arrays unidimensionais)

Nesta semana você irá manipular vetores para criar, percorrer, alterar e ordenar listas de dados, uma habilidade essencial para desenvolver algoritmos de busca e organização de informações.

Semana 11 • Aula 01

Declaração e acesso a vetores

Até o momento, nossas variáveis armazenavam apenas um único valor por vez. Quando precisamos guardar uma coleção de valores do mesmo tipo (como uma lista com 10 notas de alunos), utilizamos os vetores (arrays unidimensionais)[cite: 3].

A Estrutura de Índices

[Índice 0] → 8.5 | [Índice 1] → 7.0 | [Índice 2] → 9.2 | [Índice 3] → 6.5
  • Indexação Baseada em Zero: Em quase todas as linguagens de programação, o primeiro elemento de um vetor ocupa sempre a posição 0, o segundo a posição 1, e assim por diante até o limite de tamanho estipulado.
Semana 11 • Aula 02

Busca linear

A busca linear (ou sequencial) é o algoritmo mais simples para encontrar um elemento dentro de um vetor. Ele consiste em percorrer a lista item por item, desde o início até o final, comparando cada posição com o valor procurado[cite: 3].

  • Funcionamento: Se o elemento for encontrado, o algoritmo retorna a posição (índice) correspondente; se percorrer toda a lista sem encontrar, sinaliza que o dado não existe no vetor.
Semana 11 • Aula 03

Ordenação Bubble Sort

Para organizar os dados de um vetor em ordem crescente ou decrescente, utilizamos algoritmos clássicos de ordenação, sendo o Bubble Sort (método da bolha) o ponto de partida ideal para o aprendizado lógico[cite: 3].

Método de Ordenação Lógica de Execução
Bubble Sort Compara elementos adjacentes em pares repetidas vezes, trocando-os de lugar caso estejam na ordem incorreta, fazendo com que os maiores valores "flutuem" para o final da lista.
Semana 11 • Aula 04

Desafio – Estatísticas de vetor

Nesta aula prática, unimos a manipulação de vetores, laços de repetição e condicionais para processar estatísticas completas de um conjunto de dados[cite: 3].

Atividade Prática • Análise de Temperaturas em Vetor Escrever um programa que armazena temperaturas semanais em um vetor de 7 posições, calculando e exibindo a temperatura média, a menor temperatura registrada e a maior temperatura da semana.
