Semana 08 • Aula 01

Introdução ao while

O comando enquanto (while) permite que um bloco de instruções seja repetido diversas vezes enquanto uma condição lógica específica permanecer verdadeira[cite: 3].

A Mecânica do Laço Condicional

[Avalia Condição?] → (Verdadeiro) → Executa Bloco → Retorna ao Início
[Avalia Condição?] → (Falso) → [Sai do Loop e Segue o Fluxo]
  • Diferença para o SE: Enquanto o se executa o bloco apenas uma vez caso a condição seja verdadeira, o while repete o bloco ciclicamente enquanto a condição persistir.
Semana 08 • Aula 02

Contadores e loops sentinela

Para controlar a quantidade de repetições ou interromper a execução com base em entradas do usuário, utilizamos estratégias clássicas de controle dentro do while[cite: 3].

Estratégia de Controle Funcionamento Técnico Aplicação Típica
Contador Numérico Variável inteira incrementada a cada ciclo (ex: contador = contador + 1). Repetir um bloco exatamente N vezes (ex: contar até 10).
Valor Sentinela O loop roda até que o usuário digite um valor de parada específico (ex: digitar -1 para encerrar). Leitura de dados por tempo indeterminado até comando de saída.
Semana 08 • Aula 03

Depurando laços infinitos

Um dos erros mais comuns ao programar estruturas while é esquecer de atualizar a variável de controle dentro do bloco, fazendo com que a condição nunca se torne falsa. Isso gera um laço infinito que trava a execução do programa[cite: 3].

  • Como Identificar: O programa entra em execução contínua, congela o terminal ou consome 100% da CPU.
  • Como Corrigir: Garantir que exista uma instrução dentro do laço capaz de alterar o resultado lógico da condição de parada.
Semana 08 • Aula 04

Desafio prático – média de notas

Nesta aula prática, aplicamos o conhecimento acumulado do loop while para desenvolver um programa interativo que calcula a média de várias notas informadas pelo usuário[cite: 3].

Atividade Prática • Calculadora de Média com Sentinela Construir um algoritmo utilizando while que solicita repetidamente notas ao usuário. O programa deve parar de pedir notas quando o usuário digitar o valor sentinela -1, calculando e exibindo em seguida a média aritmética de todas as notas inseridas.
