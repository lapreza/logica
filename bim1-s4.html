Operadores relacionais

Os operadores relacionais são utilizados para comparar dois valores. O resultado de qualquer comparação relacional é sempre um valor lógico: verdadeiro ou falso.

Operador Significado Exemplo
== ou = Igual a idade == 18
!= ou <> Diferente de senha != "1234"
> Maior que preco > 100.0
< Menor que temperatura < 0
>= Maior ou igual a nota >= 7.0
<= Menor ou igual a estoque <= 5

Operadores lógicos

Quando precisamos avaliar mais de uma condição simultaneamente em um mesmo comando SE, recorremos aos operadores lógicos (E, OU, NÃO).

  • E (E / and): Retorna verdadeiro apenas se todas as condições envolvidas forem verdadeiras.
  • OU (OU / or): Retorna verdadeiro se pelo menos uma das condições for verdadeira.
  • NÃO (NAO / not): Inverte o estado lógico (o que é verdadeiro vira falso e vice-versa).
Semana 04 • Aula 03

Tabelas-verdade e análise lógica

As tabelas-verdade são ferramentas matemáticas usadas para determinar todas as combinações possíveis de resultados lógicos para expressões compostas.

[Condição A: V] & [Condição B: F] → Operador E (AND) → [Resultado: Falso]
  • Análise Preventiva: Testar as expressões na tabela-verdade antes de programar evita falhas de lógica em cenários complexos de validação de acesso ou descontos.
